## 🛠️ Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/divanshsinghsaini123/the-cocacola.git
cd the-cocacola
npm install
```

## 🏃 Usage

Run the development server:

```bash
npm start
```

Or build for production:

```bash
npm run build
```
