I want to recreate the card animation from the reference video using Three.js.

GOAL
Create a premium, Apple-like smooth 3D card carousel animation.

There are 10 cards (sections).

Each card contains:
- Image
- Title
- Subtitle
- Optional button

The animation should closely match the reference video.

------------------------------------------------------------
ANIMATION BEHAVIOR
------------------------------------------------------------

Initial State

- Only the first card is centered.
- Remaining cards are stacked behind it.
- Each card is slightly rotated on the Y-axis.
- Cards exist in real 3D space.

Example:

Card 1    z = 0
Card 2    z = -40
Card 3    z = -80
Card 4    z = -120
...

------------------------------------------------------------

While Scrolling

As the user scrolls:

Current card:
- Move slightly left
- Rotate slightly
- Scale down
- Move backward on the Z-axis

At the same time:

Next card:
- Enter from the right
- Move to the center
- Scale up
- Rotate to face the camera
- Move forward on the Z-axis

The transition should feel like cards sliding and swapping positions in 3D, not fading.

------------------------------------------------------------

Motion

Use smooth easing such as:

- power3.inOut
- expo.inOut

Animation should have momentum.
No snapping.
No sudden changes.

------------------------------------------------------------

Depth

Animate using:

- position.x
- position.y
- position.z
- rotation.x
- rotation.y
- scale

The camera remains fixed.
Cards move instead.
